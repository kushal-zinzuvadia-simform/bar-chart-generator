# Bar Chart Generator

## Goal
Build a React app that lets users enter X-axis labels and Y-axis values, then displays a bar chart.
 
## Requirements
- Feature to add X-axis and Y-axis data
- Generate bar chart from the entered data
- Build the chart without any third-party chart library
- Proper validations for chart data
 
## Rules
- Use React
- Use HTML/CSS or SVG for the chart
- Do not use Chart.js, Recharts, D3, or similar libraries
